# Forecast

A simple weather website. It shows the weather for your location and lets you search for any city.

## Features

- Current weather, feels like, high and low
- Next hours and 7-day forecast
- Humidity, wind, UV index, pressure, visibility, sunrise and sunset
- City search with suggestions as you type
- °C / °F switch
- Works on desktop and phone

## Built with

- HTML, CSS and JavaScript
- [Open-Meteo](https://open-meteo.com/) for weather and city search
- [BigDataCloud](https://www.bigdatacloud.com/) to get the name of your location

## Run it

1. Download or clone the project.
2. Open the folder in VS Code and start it with Live Server, or run any local server.
3. Open the page and allow location access, or search for a city.

## Files

- `index.html` – the page
- `styles.css` – the design
- `script.js` – fetches and shows the weather
